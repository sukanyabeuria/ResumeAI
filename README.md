# ResumeAI

An AI-powered resume builder that helps users create professional resumes quickly using customizable templates.


## Overview

ResumeAI is a web application designed to make resume creation simple and fast.

Users can enter their personal information, education, skills, experience, projects, and other details. The application organizes the information into professional resume templates that can be customized for different career needs.

## Features


- AI-powered resume generation
- Multiple professional resume templates
- Easy-to-use resume builder
- Student and fresher-friendly templates
- Modern and responsive interface
- Resume preview
- Different template styles for different career goals
- Structured sections for:
  - Personal Information
  - Education
  - Skills
  - Experience
  - Projects
  - Certifications
  - Achievements

## Templates

ResumeAI includes multiple resume designs:

- Classic
- Creative
- Executive
- Minimal
- Modern
- Professional
- Student
- Tech
